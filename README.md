# Kynx Project One

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> Developer website — personal portfolio & project showcase built with a modern, minimal approach.

## ✨ Fitur Utama

- ✅ Halaman profil & bio developer
- ✅ Showcase project dengan tautan langsung
- ✅ Desain responsif (mobile, tablet, desktop)
- ✅ Fast load & SEO-friendly

## 🛠️ Tech Stack

| Kategori | Teknologi |
| --- | --- |
| Bahasa | HTML, CSS, JavaScript |
| Hosting | GitHub Pages / Vercel |
| Lainnya | Git, GitHub Actions (opsional) |

## 📦 Instalasi

    # Clone repository
    git clone https://github.com/kenza11-star/Kynx-projectone.git

    # Masuk ke direktori
    cd Kynx-projectone

    # Jalankan secara lokal (buka index.html, atau pakai live server)
    npx serve

## 🚀 Penggunaan

Setelah aplikasi berjalan, buka http://localhost:3000 di browser untuk melihat hasilnya.
